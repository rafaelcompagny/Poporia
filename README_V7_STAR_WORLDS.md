# Poporia V7.0 — Star Worlds & Premium Path

## Mondes verrouillés par étoiles
Le passage dans les mondes avancés demande désormais à la fois d'avoir atteint le monde et un nombre minimum d'étoiles :
- Poporia City : 0
- Poporia Forest : 12
- Crystal Caves : 45
- Poporia Beach : 72
- Sky Kingdom : 100
- Volcano Pop : 128
- Neon Galaxy : 158
- Royal Peaks : 188

Les conditions sont affichées directement dans le sélecteur de mondes.

## Carte des niveaux
- Médaillons de niveaux entièrement retravaillés.
- Trois vraies étoiles visuelles au-dessus de chaque niveau.
- Étoiles gagnées dorées / non gagnées grisées.
- Cercle spécial pour le niveau actuel.
- Verrou plus lisible pour les niveaux fermés.
- Plateformes flottantes avec plusieurs couches de profondeur.
- Ponts 2.5D avec planches, rails et poteaux.
- Style de plateforme et passage différent selon Caves, Sky, Volcano, Galaxy et Royal.

## Gameplay
Aucune mécanique de niveau ou sauvegarde existante n'est supprimée.
Firebase, Stripe et le backend restent inchangés.
