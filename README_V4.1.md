# Poporia V4.1 — Onboarding & règles de grille

Cette mise à jour prépare le jeu avant l'extension de contenu.

## Tutoriel obligatoire et interactif
- Le bouton Continuer lance le tutoriel tant qu'il n'a pas été terminé.
- Le joueur doit réellement effectuer les actions demandées.
- Les cases à utiliser sont mises en évidence.
- Étapes : Match-3, fusée, activation de fusée, bombe, prisme.
- Une fois terminé, le tutoriel peut être rejoué librement.

## Tutoriels de nouvelles mécaniques
À la première apparition d'une mécanique, une fiche bloque brièvement le jeu et explique :
- ❄️ glaçon ;
- 📦 caisse ;
- ⛓️ chaîne ;
- 🫧 gelée.

L'information n'est affichée qu'une fois par compte grâce à `seenFeatureTutorials`.

## Glaçon
Un Pop placé dans une case gelée ne peut plus être déplacé tant que la glace n'est pas cassée.
Une tentative de déplacement affiche une explication au joueur.

## Interface
- Objectif de niveau agrandi.
- Compteur de coups agrandi.
- Suppression du bloc « Prisme + boost / Transforme 15 Pops normaux » dans l'aide latérale.

## Prochaine étape prévue
Plus de niveaux, Pass de saison, nouveaux obstacles, nouveaux objectifs et niveaux chronométrés.
