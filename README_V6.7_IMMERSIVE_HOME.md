# Poporia V6.7 — Immersive Home

## Correction importante
Les écrans de Poporia sont désormais strictement isolés :
- `.screen` est masqué par défaut ;
- seule la page `.active` est affichée ;
- l'écran de jeu ne peut plus apparaître sous la page d'accueil.

## Nouvelle page d'accueil
- Suppression de la démonstration de Pops qui ressemblait à un schéma technique.
- Nouveau décor Poporia avec île flottante, château, arbres, nuages et étincelles.
- Nouveau fond général violet / crème beaucoup moins vide.
- Carte du monde actuel transformée en petit paysage.
- Cartes Missions / Événements intégrées plus naturellement au décor.
- Adaptation spécifique téléphone.

Aucun changement dans Firebase, Stripe, les sauvegardes ou les mécaniques du jeu.
