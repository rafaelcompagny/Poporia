# Poporia V2.2

Nouveautés :
- Offre de continuation : +5 coups pour 500 pièces, sans perdre de vie.
- Une vie se régénère toutes les 10 minutes.
- Responsive téléphone retravaillé pour afficher la grille et les contrôles dans la hauteur disponible.
- Codes promo. Codes de test inclus : V1 = 3 marteaux, POPORIA = 500 pièces, ROCKET = 2 fusées. Chaque code est utilisable une seule fois par compte.
- Boutique de bombes, fusées et prismes, stockés dans l'inventaire et posables directement en jeu.
- Packs de pièces affichés avec prix en euros, mais entièrement simulés : aucun paiement réel n'est effectué.

Firebase : aucune nouvelle collection n'est nécessaire pour cette version ; les nouveaux champs d'inventaire et codes utilisés sont sauvegardés dans le document users existant.
