# Poporia V4.2 — Extension de campagne

## Campagne
- 60 niveaux.
- Monde 5 : ☁️ Sky Kingdom (41–50).
- Monde 6 : 🌋 Volcano Pop (51–60).
- Boss : 10, 20, 30, 40, 50 et 60.
- Niveaux spéciaux : 5, 15, 25, 35, 45 et 55.

## Nouveaux obstacles
- 🪨 Rocher : bloque le déplacement du Pop jusqu’à destruction.
- 🌫️ Brouillard : masque la case et doit être dissipé.
- 🌋 Lave : case dangereuse à nettoyer.
- Tutoriel automatique à la première apparition de chaque mécanique.

## Nouveaux objectifs
- Détruire tous les rochers.
- Dissiper tout le brouillard.
- Nettoyer toute la lave.
- Les anciens objectifs restent disponibles.

## Niveaux chronométrés
Plusieurs niveaux à partir de Sky Kingdom ont un chrono.
Le petit tutoriel d’une nouvelle mécanique met le démarrage du chrono en attente.
Si le temps expire, la partie peut être prolongée de 15 secondes pour 500 pièces.

## Pass de Saison
- Saison 1 : Éclats de Poporia.
- 20 paliers.
- XP gagnée en remportant des niveaux.
- Les Boss donnent davantage d’XP.
- Récompenses gratuites : pièces et coffres.
- Voie Premium simulée : pièces et prismes.
- Activation Premium factice pour le moment, sans paiement réel.

## Préparation V5
La structure `seasonPass` est sauvegardée dans le profil afin de préparer les futures fonctions :
mode infini, classement saisonnier, profil social, succès, amis, coffres enrichis,
boutique tournante, nouveaux mondes, notifications internes, statistiques admin et skins de Pops.

La V6 prévue pourra ensuite remplacer les achats simulés par une boutique Stripe réelle.
